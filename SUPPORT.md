# Support

## Choose the right channel

- **Bug:** GitHub Issues
- **Feature proposal:** GitHub Discussions first, then an issue after agreement
- **Implementation question:** GitHub Discussions
- **Sensitive accessibility report:** `hi@upliftiq.in`
- **Security vulnerability:** follow [SECURITY.md](./SECURITY.md)

This is a community open-source project. Response times are not guaranteed. Please include a minimal reproduction and avoid private user data.
